# 阶乘计算器

## 项目简介
一个简单的 C++ 程序，接收用户输入的整数并输出它的阶乘。

## 目录结构
\```
.
├── include/
│   └── factorial.hpp
├── src/
│   ├── factorial.cpp
│   └── main.cpp
├── CMakeLists.txt
├── .gitignore
└── README.md
\```

## 环境要求
- Ubuntu 22.04
- CMake >= 3.8
- C++ 编译器（如 g++）

## 运行方式
\```bash
mkdir build
cd build
cmake ..
make
./factorial
\```
